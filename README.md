# MD Preview Bridge

> Open your Markdown files in a full-screen browser preview, with two-way sync back to VSCode.

📦 **Install from Open VSX**: https://open-vsx.org/extension/hwanpenn/md-preview-bridge

## Features

- 🌐 One-click open in system browser
- 🔗 Real-time two-way sync with VSCode (Cmd+S saves back to the original file)
- 🛡️ Conflict detection to prevent overwriting unsaved changes
- 🎨 GFM support (tables, task lists, code highlighting)
